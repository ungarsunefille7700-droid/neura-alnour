# NeuraCo 1.0.0

Premiere version Windows x64 preparee pour GitHub Releases.

## Fonctions principales

- ouverture et analyse de projets locaux ;
- conversation persistante et contexte projet ;
- edition de fichiers et revue des differences ;
- terminal integre et processus en arriere-plan ;
- Git, branches, worktrees et checkpoints ;
- permissions, confirmations et arret d'urgence ;
- agents specialises et orchestration ;
- navigateur, documents et outils de projet ;
- authentification avec le compte Neura Al-Nour ;
- consommation, quotas et historique ;
- stockage local protege et reprise apres fermeture.

## Installation

Telechargez `NeuraCo-Setup-v1.0.0.exe`, verifiez le fichier `SHA256SUMS.txt`, puis ouvrez l'installateur. Aucun runtime a installer manuellement n'est necessaire.

## Signature

Cette edition GitHub gratuite est non signee. Windows SmartScreen peut afficher un avertissement. Le hash SHA-256 publie permet de verifier l'integrite exacte du fichier telecharge.

## Services en ligne

L'authentification et les fonctions IA necessitent une connexion au backend Neura Al-Nour. Aucune cle API privee n'est incluse dans l'installateur.
