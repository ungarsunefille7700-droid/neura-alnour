# NeuraCo 1.0.1

Cette mise a jour rend les options de connexion et de creation de compte directement accessibles dans l'application Windows.

## Nouveautes

- Connexion Google visible des l'ouverture de NeuraCo.
- Creation de compte Neura Al-Nour depuis l'application Windows.
- Formulaire d'inscription avec nom, e-mail, mot de passe et confirmation.
- Interface de connexion simplifiee et inspiree des assistants modernes.
- Passage immediat entre connexion et inscription, sans quitter NeuraCo.

## Securite

- L'inscription passe par le backend Neura Al-Nour existant.
- Le mot de passe n'est jamais conserve par l'application Windows.
- Le jeton de session reste protege par le stockage chiffre de Windows lorsqu'il est disponible.
- Aucune cle API ni aucun secret serveur n'est inclus dans l'installateur.

## Installation

Telechargez `NeuraCo-Setup-v1.0.1.exe`, verifiez le fichier `SHA256SUMS.txt`, puis ouvrez l'installateur. Aucun runtime supplementaire n'est necessaire.
