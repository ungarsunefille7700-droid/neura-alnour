# NeuraCo 1.0.3

## Correctif

- Le compositeur de l'accueil accepte maintenant les demandes sans qu'un projet soit ouvert.
- Les réponses IA sont affichées directement dans le fil d'accueil.
- La touche Entree envoie la demande et Maj+Entree conserve un retour a la ligne.
- Le bouton `+` ouvre toujours un projet local quand un contexte de fichiers est nécessaire.
- Une conversation sans projet n'envoie aucun fichier local au serveur.

## Verification

- Tests de l'interface d'accueil réussis.
- Build Electron, CLI, SDK et interface réussi.
- Installateur Windows x64 autonome contrôlé avant publication.
