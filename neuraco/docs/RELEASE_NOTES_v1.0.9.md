# NeuraCo 1.0.9

## Generation de projets

- Contrat de generation FiveM renforce : questions utiles avant une demande ambigue, fichiers complets et absence de pseudo-code.
- Ressources FiveM pretes a installer avec manifeste, configuration, scripts client/serveur, README et protections serveur selon le besoin.
- Propositions multi-fichiers toujours examinees puis confirmees avant leur ecriture reelle dans le projet.

## Validation et export

- Validation locale d'un projet depuis l'explorateur NeuraCo.
- Controle des manifestes FiveM et detection des fichiers references manquants.
- Export ZIP du projet ouvert avec confirmation en cas d'erreur, compteur de fichiers et empreinte SHA-256.
- Exclusion automatique des secrets, fichiers `.env`, dependances, metadonnees Git et liens symboliques.

## Outils Windows

- Controle Windows confirme pour les applications autorisees avec inspection UI Automation, previsualisation et validation avant action.
- Integrations FiveM, Blender et 3ds Max conservees avec validation et exports structures limites au projet ouvert.
- Arret d'urgence, journal local et protections de chemin maintenus.

## Verification

- 81 fichiers de test et 321 tests NeuraCo reussis.
- 51 tests backend NeuraCo reussis.
- Builds Electron, CLI, SDK et interface Windows controles.
- Analyse des dependances de production et recherche de secrets validees.
